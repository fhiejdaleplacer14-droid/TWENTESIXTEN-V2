Your own music (optional, stays on your computer)

Put audio files here with these names, and the game plays them instead of its
own folk songs:

  radio.mp3    the radio at the sari-sari store (loops; louder as you walk up to it)
  golden.mp3   when the light turns golden (plays once)
  ending.mp3   the ending, on the bench with Lola (plays once)

.ogg, .m4a and .wav work too. Run the game with `npm run dev`.

Everything in this folder except this file is ignored by git, so it is never
pushed to GitHub. Only use songs you are allowed to use. Don't publish a build
(npm run build, itch.io, GitHub Pages) with songs you don't own in it: the build
copies this folder.
